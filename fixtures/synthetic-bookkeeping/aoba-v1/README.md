# 青葉雑貨店 複式簿記練習フィクスチャ（合成・未承認）

これは架空の個人商店「青葉雑貨店」のための、複式簿記の練習問題20問と答え合わせ用データである。

**合成された未承認の教材である。専門家の監修を受けていない。監修済み、検定対策の公式教材、会計基準や税法への準拠とは主張しない。**

扱わないもの:

- 現行税法、税率、消費税の区分、所得計算、申告、法的助言
- 公式試験問題の転載
- 実在の事業者、個人、口座
- 減価償却、貸倒、期末棚卸、売上原価、決算振替

金額は整数の日本円だけである。物語の日付 `20X6-04-**` は架空であり、実在の会計年度を指さない。

## 問題のつながり

20問は同じ架空商店・同じ勘定科目・同じ会計仮定を共有する。**各問は独立**である。前問の元帳を次問の期首に引き継がない。期首が必要な問は、その問の `opening_balances` に完結して書いてある。空配列は、その問の開始時点で全勘定がゼロという意味である。

## 会計上の仮定

詳細は [assumptions.json](assumptions.json)。要点だけ書く。

- 複式簿記。仕訳は借方1行・貸方1行の単純仕訳だけ。
- 商品は三分法のうち、仕入は仕入勘定、売上は売上勘定に記録する部分だけ。繰越商品と売上原価は出さない。
- 元入れは現金／資本金。
- 掛売上は売掛金／売上。掛仕入は仕入／買掛金。
- 回収・支払は債権債務と現金または普通預金の入出金であり、売上・仕入・費用の再計上ではない。
- 前払は費用処理法。次期以降分の金額は問題文が直接指定する。日数・月数の按分はしない。
- 未払の新規計上は費用／未払費用。期首未払の支払は未払費用／現金（または預金）であり、費用を重ねない。
- 期待する試算表は残高試算表。差引ゼロの勘定は元帳には残し、試算表の行からは除く。

## ファイル

| ファイル | 役割 |
| --- | --- |
| assumptions.json | 会計仮定、独立性、対象外 |
| chart_of_accounts.json | 勘定科目表（コード、貸借対照表か損益か、正常残高側） |
| schema.json | problems.json と兄弟ファイルの形（JSON Schema draft 2020-12） |
| problems.json | 20問。問題文、期首、期待する借方貸方、説明、期待元帳、期待試算表 |
| validator.py | 依存なしの検査。期首＋仕訳を転記し、期待元帳と期待試算表と照合する |
| test_fixture.py | オフラインの unittest。別実装の足し算と、直書きの金額ロールフォワードを含む |

`problems.json` の `prompt_ja` と `opening_balances` が問題、`expected_entries` 以降が答えである。

## 検査で見ること

借方合計と貸方合計が一致するだけでは合格にしない。

1. 各仕訳の借方＝貸方、期首残高の借方＝貸方
2. 期首に期待仕訳を転記した借方合計・貸方合計・差引が `expected_ledger` と一致
3. そこから作った残高試算表が `expected_trial_balance` と一致し、合計も一致
4. 正常残高側と逆の残高が残っていない
5. 残高ゼロの勘定が試算表に出ていない

学習者の仕訳は `validator.grade_attempt` で採点する。日付・仕訳番号・借方貸方の勘定と金額を期待値と比較し、さらに転記結果を期待元帳・期待試算表と比較する。摘要の文言差だけでは落とさない。貸借が一致していても勘定や金額が違えば不合格になる。

## 実行

追加インストールは不要である。このディレクトリで次を実行する。

```bash
python3 validator.py check
python3 -m unittest test_fixture.py -v
```

ネットワーク通信、外部API、資格情報、公開、デプロイは使わない。
