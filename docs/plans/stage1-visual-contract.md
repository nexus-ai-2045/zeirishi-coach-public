# 第1段階の画面契約

全体設計はPRODUCT_SPECが正本。本書は第1段階の表示・ローカル検証範囲のみ。

Image Genで作成した全画面コンセプトを実装担当が採用。白背景、紺文字、teal操作色、資料と答案の2列、下段に復習。本文は日本語sans-serif、見出し32–44px、本文16–20px、44px以上の操作領域。画面幅760px以下では資料→答案→復習の1列へ。写真・キャラクター・戦闘・画像化した操作部品は使わない。

主要コピーは「税理士コーチ」「開発用・テスト教材」「利益と現金は、なぜ違う？」「資料を読み、今期の費用を考えてみましょう。」「資料を読む」「答案をつくる」「振り返る」「相談メモ」「今期の費用はいくら？」「下書きを保存」「提出して振り返る」「次の復習」。保存・競合・通信失敗・採点結果の動的文言と最初の開始操作は機能上必要な派生。固定の保存成功表示はしない。

ローカル検証のDBはサーバー内PGliteのfilesystem版を使用する。PostgreSQL WASMを既存パッケージとして利用し、独自JSONストアを作らない。単一プロセスのテスト環境であり、本番PostgreSQL/Supabaseの並行接続・RLS・Magic Link検収ではない。公式根拠: https://pglite.dev/docs/ と https://pglite.dev/docs/filesystems 。本番採用の変更ではなく、契約前の隔離fixture検証用adapter。

外部AIなし、実利用者なし、架空データだけ。loopback専用・明示fixture有効化が必須で、有効化されていない起動ではAPIを拒否する。第2段階の認証を実装済みと称さない。
