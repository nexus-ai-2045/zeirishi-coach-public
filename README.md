# 税理士コーチ

採用した公開ソースの正本は [nexus-ai-2045/zeirishi-coach-public](https://github.com/nexus-ai-2045/zeirishi-coach-public) です。以後のコード変更はこの正本で扱います。元のリポジトリは非公開の原資料保管庫として残します。公開リポジトリの作成・送信状況は別途検収します。

簿記論の学習者向けに、実務を題材にした相談と説明練習で理解を確かめ、復習へ進む学習アプリです。合格を保証するものではありません。

## 目的

考え方を実務の判断と説明につなげ、学習した内容と未確認の領域を見えるようにします。

## できること

簿記論の36概念、架空の相談35件、練習240問をローカルで試せます。診断・評価・保持確認・ミニ演習には練習と別の原稿228問を用意しています。既存28論点とCF・包括利益まで分類を広げました。全範囲の網羅・正答・年度適用は専門審査前です。[収載範囲と残る処理](docs/materials/bookkeeping-syllabus-review.md)を確認できます。他科目へは広げていません。

## 制約

専門審査済み教材を備えた正式`MVP`ではありません。実学習者への提供・招待は未検収です。この試用では架空の情報を使ってください。

## 試用の進み方

最初はホームから「簿記の全体像」を開いて図と仕組みを確認し、「学習地図へ進む」から概念を選びます。地図は簿記論から大分類・論点へ枝分かれするツリーです。枝を開いて現在地と練習状況を見たり、「考え方で見る」へ切り替えて概念のつながりをたどったりできます。確認済みの表示は適格な評価記録から導き、原稿試用の正解で習熟を認定しません。相談では、相談内容 → 資料と4択 → 結果と根拠の図 → 自分の説明・問い返し → 振り返りの順に、一段階ずつ表示します。資料は判断中に見返せますが、確定前に正解や解説は表示しません。

開始時は短いミッション、回答後は根拠の図、完了時は大きな達成カードと粒子で手応えを示します。誤答にも次に確認する点を示します。演出は約1秒で操作を止めず、「演出を控える」と端末の動き削減設定に対応します。音は鳴りません。再読込では達成演出を繰り返しません。

進行中の相談がある場合、ホームの主操作は「続きから」です。ブラウザーの戻る・進むや再読込でも保存済みの相談へ戻れます。保存に失敗した入力は画面に残り、再試行または明示保存できます。学習記録には診断・週間計画・提出済み履歴・模試の参考記録・本人データ管理をまとめます。自己申告やこの合成教材の試用結果は、正式な習熟・合格ラインの証拠ではありません。

## クイックスタート

`Node.js` 24.20.0 を用意し、リポジトリ直下から実行します。

```bash
cd web
npm ci
ZEIRISHI_FIXTURE_MODE=1 ZEIRISHI_BOOKKEEPING_MVP=1 npm run dev
```

`http://127.0.0.1:3210` で開発用相談を体験できます。ローカルの合成データ専用です。終了は端末で `Ctrl+C`。同じ保存先に複数のサーバーを起動しないでください。

macOSで、端末や会話の終了後も確認用画面を動かす場合は、開発サーバーを終了してから次を実行します。現在のログイン中だけ動き、ログイン時の自動起動は登録しません。

```bash
npm run build
sh scripts/local-preview.sh start
sh scripts/local-preview.sh status
# 確認を終えたら
sh scripts/local-preview.sh stop
```

この確認用起動はローカル原稿専用で、外部の認証・保存・対話接続を無効にします。ログは `web/.local-data/preview` に保存します。使用中の3210番ポートや所有を照合できない処理は停止しません。

壁打ちは、既定では固定の問いで理解を確かめます。外部の`AI`を使う場合の設定・送信範囲は[開発用参考資料](docs/plans/development-reference.md)で確認してください。返答で採点や習熟判定は変わりません。
